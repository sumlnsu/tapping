1. 모으는 정보

회원이메일, 비밀번호(암호화되어 로그인 서비스에만 저장), 찜·별로예요·취향 점수·시작 설정, 넘김·찜·구매 클릭 기록
모든 방문자
(익명 이용 통계)		기기마다 만든 임의 번호, 방문 번호, 본 상품·찜·별로예요·구매 클릭, 기기 종류(휴대폰·태블릿·PC), 들어온 사이트 주소, 첫 화면 로딩 시간, 앱 버전. 이름·이메일·IP 주소·위치는 통계에 저장하지 않아요. 로그인한 상태면 회원 번호가 함께 기록돼요.

2. 쓰는 곳

  • 로그인, 찜 목록 저장, 여러 기기에서 같은 찜 보기
  • 반응을 학습해 취향에 맞는 상품 추천
  • 방문자 수·재방문율·많이 본 상품 같은 서비스 개선 지표

3. 보관 기간

  • 회원 정보: 탈퇴할 때까지. 탈퇴 기능을 준비하는 동안에는 요청하시면 바로 지워 드려요.
  • 익명 이용 통계: 모은 날부터 2년

4. 맡겨서 처리하는 곳

  • Supabase — 로그인, 찜·반응 기록, 이용 통계 저장
  • GitHub Pages — 사이트 호스팅 (접속 기록은 GitHub 정책에 따름)
  • Cloudflare R2 — 상품 사진 배경 처리용 이미지 (개인정보 없음)

5. 고를 수 있는 것

  • 익명 이용 통계 끄기: 오른쪽 위 사람 아이콘 → 익명 이용 통계 보내기 끄기
  • 이 기기의 기록 지우기: 브라우저 설정에서 이 사이트의 데이터 삭제

6. 판매처로 이동한 뒤

구매하러 가기를 누르면 각 판매처 사이트로 이동해요. 그 뒤의 정보 처리는 해당 판매처의 방침을 따라요.

7. 바뀔 때

정식 서비스 전환 등으로 내용이 바뀌면 이 페이지와 앱 안에서 먼저 알려 드려요.
