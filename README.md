# 태핑 (Tapping) — 베타

고르지 말고, 넘기세요. 성별·카테고리·가격만 정하면 감도 높은 패션 아이템을 한 장씩 보여 주는 원탭 큐레이션 앱입니다.

- 빈 곳 탭: 다음 상품 · ❤️ 찜 · 👎 별로 · 🛍️ 구매 페이지로 이동
- 로그인 없이 넘겨 보기와 구매 링크를 쓸 수 있고, 찜·싫어요·취향 맞춤 추천은 로그인 후 저장됩니다 (자동 로그인 지원)
- 계정·찜·반응 기록은 Supabase에 저장되며, 각 회원은 본인 기록만 읽고 쓸 수 있습니다 (RLS)
- 상품 이미지·가격·링크의 권리는 각 브랜드와 판매처에 있으며, 구매는 각 판매처에서 이루어집니다

파일: `index.html` 화면 · `app.js` 피드·추천 · `account.js` 로그인·동기화 · `config.js` Supabase 주소/공개 키 · `feed.js` 상품 데이터
